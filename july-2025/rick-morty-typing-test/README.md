# Rick and Morty Typing Speed Test

An interdimensional typing speed test inspired by the Rick and Morty universe. Test your typing skills across different difficulty levels while enjoying quotes from the show!

## Features

- **Three Difficulty Levels:**
  - Jerry Mode (Easy) - Short, simple phrases
  - Morty Mode (Medium) - Medium-length quotes from the show
  - Rick Mode (Hard) - Long, complex Rick rants

- **Real-time Statistics:**
  - Words Per Minute (WPM)
  - Accuracy percentage
  - Live timer countdown

- **Rick and Morty Theme:**
  - Portal-inspired animations
  - Green sci-fi color scheme
  - Character quotes and commentary
  - Interactive visual effects

- **Performance Feedback:**
  - End-of-test results summary
  - Rick's personalized comments based on your performance
  - Total characters typed tracking

## How to Play

1. Select your difficulty level
2. Click "Start Test" to begin
3. Type the displayed quote as quickly and accurately as possible
4. Complete as many quotes as you can within 60 seconds
5. Review your results and Rick's commentary!

## Technologies Used

- HTML5
- CSS3 (with animations and effects)
- Vanilla JavaScript
- Google Fonts (Creepster & Press Start 2P)

## Setup

Simply open `index.html` in a modern web browser to start testing your typing speed!

## Files

- `index.html` - Main HTML structure
- `styles.css` - Rick and Morty themed styling and animations
